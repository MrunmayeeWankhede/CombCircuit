# CombCircuit

A research workbench for the balance-organ circuit of the comb jelly
*Mnemiopsis leidyi*. The question: when does treating a syncytial neuron as one
electrical unit hide effects that appear when activity varies along its arbor?

The anatomy is measured. The membrane properties and synaptic effects are
assumptions. This is an exploratory model-comparison prototype, not a validated
simulation of a whole animal.

## Open the explorer

Unzip this folder, then double-click **EXPLORE.html**. No Python installation,
account or internet connection is needed. The controls replay precomputed runs.

1. Drag the arbors to rotate. Scroll to zoom.
2. Set **Color** to **Simulated voltage**, then press **Play**.
3. Switch between **Spatial arbor** and **Equipotential cells**.
4. Compare the central cell mean with **Stimulated compartment · local**.
5. Try bridge-feedback removal and the virtual cable cut.

The white ring is a hypothetical current-injection site. A gold × marks the cut.
Only the three ANN arbors are drawn. Bridge and balancer cells are included in
the equations without assigning them invented 3D shapes.

## What is included

- 158 selected cells: 3 ANN cells, 26 bridge cells, 129 balancer cells.
- 280 measured directed contacts, comprising 113 directed cell pairs.
- Three source CATMAID arbors with all modeled ANN synaptic treenodes matched.
- Point and spatial models with matched membrane capacitance and current input.
- Four comparison runs and an 18-scenario parameter sweep.
- Exact source files, SHA-256 hashes, CSV outputs, figures and numerical tests.

We did not map these cells. The reconstruction is the work of Jokura, Jasek,
Niederhaus, Burkhardt and Jékely. The project's contribution is this exploratory
workbench built on their data.

## Reproduce the analysis

Use Python 3.11 or newer. In Terminal, enter `cd `, drag this unzipped folder into
the Terminal window, and press Return. Then run:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python combcircuit.py
```

On Windows activate with `.venv\Scripts\activate`. Package installation needs
internet; subsequent runs use bundled source data. Use `python combcircuit.py
--quick` to skip the sensitivity sweep. Run environment versions are recorded in
`results/summary.json`. Results and the explorer are regenerated by the script.

To change a hypothesis:

```python
from dataclasses import replace
from combcircuit import Parameters, build, simulate
p = replace(Parameters(), radius_um=0.1, synaptic_sign=-1)
r = simulate(build('spatial', p, bridge_feedback=False))
print(r['metrics'])
```

Negative sign is an alternative all-contact hypothesis, not a measured
neurotransmitter assignment. The default assumes all contacts are excitatory.

## Interpreting the results

Different traces show consequences of model assumptions and geometry. They do
not show which model is biologically correct. The spatial model is not fitted
to the animal. More detailed anatomy does not automatically make it more accurate.

ANN readouts are capacitance-weighted mean deviations from rest. Balancer
readouts are modeled electrical drive, **not ciliary beat frequency or swimming**.
We have not modeled active ion channels, calcium fluorescence, ciliary mechanics,
learning or whole-body behavior. Ciliary source data are included as future
validation targets; they are not treated as neural-voltage recordings.

The exported arbors are rooted trees. They do not establish all anastomotic loops
of continuous syncytial tissue. Missing radii are not measured: a uniform radius
is explicitly assumed, including in traced soma regions. No nearby branches are
joined without evidence. See docs/MODEL.md and docs/DATA_AUDIT.md.

Use docs/STUDY_PLAN.md to move from this implementation to a defensible question:
